## About

Technology and security leader with an operator’s mindset and an architect’s curiosity, comfortable moving from executive strategy into system design, threat modeling, AI security, and technical validation.

Applies machine learning, generative AI, and agentic workflows to engineering and security problems. Work includes bespoke internal tools, customer-facing developer platforms, and applied research, with an emphasis on reducing operational toil, making security capabilities more accessible, and defining clear boundaries for AI-assisted and autonomous workflows.

Chief Information Security Officer at Sharpen Technologies. Runs and manages R&D and IT across Sharpen, Plum Voice, Webtext, and Ytel, with responsibility for engineering, CloudOps, and product management. Also serves as Professorial Lecturer & Doctoral Advisor in Cybersecurity Analytics at The George Washington University.

Previously spent 15 years as CTO at Ytel, responsible for the entire technology organization, including software engineering, platform architecture, infrastructure, operations, and security.

Early work at NQL in 2001 involved intelligent agents and content aggregation.

## Selected Work

| Project | What it is |
| --- | --- |
| **AegisShield** | Public AI threat modeling and workflow testing, developed from doctoral research. Specialist-agent review, ATT&CK/ATLAS mapping, four model providers, NeMo safeguards, and garak scans. Published safeguard results use a simulated model. [Code on GitHub](https://github.com/mgrofsky/AegisShield) · [Read the praxis](https://www.proquest.com/docview/3233915741) |
| **AegisShield for Healthcare** (private) | Healthcare-focused security assessment with organization-specific context, assessment history, and traceable evidence. [Project overview](https://mgrofsky.github.io/#aegisshield-healthcare) |
| **Boundary Lab** | **Redline** checks chatbot answers against rules. **Dye** traces tool-call values back to source text. **Latch** checks permissions, approvals, and limits before calls run. [Redline](https://github.com/mgrofsky/boundary-lab/tree/main/redline) · [Dye](https://github.com/mgrofsky/boundary-lab/tree/main/tools/dye) · [Latch](https://github.com/mgrofsky/boundary-lab/tree/main/tools/latch) |
| **Winnie the Agent** | Adaptive honeypot extending DECEIVE with simulated services, adaptive decoys, and response playbooks. Automates local reactions; enforcement requires human approval. Includes draft detections and optional SIEM export. [Code on GitHub](https://github.com/mgrofsky/winnie-the-agent) · [Project overview](https://mgrofsky.github.io/#winnie-the-agent) |
| **Large-Scale APIs & MCP** | An omnichannel communications developer platform with a secure MCP layer: 15 curated tools and discovery across 216 REST endpoints. [API documentation](https://api-docs.ytel.com/) |
| **Pentest Arsenal** (private) | Autonomous red-team and blue-team operations inside hard guardrails: target validation, allowlists, phase budgets, audit records, and regression tests. |
| **Cloud Detection & AI-Assisted Investigation** | Custom cloud and identity log pipelines, Wazuh detection, person-specific network baselines, and Claude on Bedrock for analyst-guided investigation. [Project overview](https://mgrofsky.github.io/#alert-triage) |
| **Incident Investigator** (private) | An AI investigation workspace that hunts service outages and security incidents across live sources, then turns closed cases into ranked precedents. |
| **PCI, HIPAA & SOC 2 Mock Auditor** (private) | A read-only AI assessor that audits live cloud, infrastructure as code, and application repos against PCI DSS, HIPAA, and SOC 2, separating documented policy from operating evidence. |
